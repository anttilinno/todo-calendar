       - Parse checksumFile: expect format "hexhash  filename\n" (sha256sum output format) or just the hex hash
       - Compute SHA256 of binary
       - Compare hex strings (case-insensitive)
       - Return nil on match, fmt.Errorf with details on mismatch

    Refine DownloadRelease for testability: make the function accept a custom http.Client or a baseURL override.     Final API design:
    - CheckForUpdate(currentVersion string) (*Release, error) where Release has Tag, BinaryURL, ChecksumURL fields
    - When no update available, returns nil, nil
    - DownloadAsset(url string) ([]byte, error) — downloads a single URL with timeout
    - VerifyChecksum(binary []byte, checksumFile []byte) error
